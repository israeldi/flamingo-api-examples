# TableNest CSV export: approved support procedure

Fictional training example only. TableNest is not a real service in this example.
Source ID: tablenest-csv
Version: 1.0
Approved owner: TableNest support team (fictional fixture).
Scope: a user-authorized CSV download from a saved report; this procedure does not change report data.

Use a fictional or otherwise authorized report. Do not include passwords or customer records in a support summary.
After selecting Export CSV, first check whether a file appeared in the browser's download list.
If a file appeared, check whether the file opens in the user's ordinary spreadsheet or text application.
If the file does not open, keep the original download and ask the support owner for import instructions; do not edit or overwrite the file.
If the file opens, compare its column headings with the saved report's displayed column headings.
If the headings match, the next step is to review the downloaded rows using the normal report-review process. Opening the file does not prove that its data is correct.
If headings differ, stop and ask the report owner which saved report and columns were intended. Do not silently rename or remove columns.
If no file appeared, check whether the application displays an Export queued banner for the same saved report.
If Export queued is displayed, leave that job unchanged and wait for the application to offer its download; do not start another export while that banner is present.
If no file appeared and no Export queued banner is present, select Export CSV once more. If no file then appears, ask the support owner; do not continue retrying.
If any observation is unknown, unclear, or does not fit these choices, stop and ask the support owner. Do not guess a remedy.
When asking for help, share the saved-report name, the visible banner or error text, and the steps already taken. Omit file contents and credentials.
This procedure authorizes only the stated manual next steps. Reaching a guide outcome does not establish that the issue is resolved.
