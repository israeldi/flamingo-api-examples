# File and workflow skills on Agensi

Start with the job you want to automate. The examples in this repository use fictional materials and show the files you can expect your agent to return. The Agensi listing gives you the current price, supported inputs and purchase terms.

| If you need to | Choose | See an example |
| --- | --- | --- |

| Check that a particular ebook delivery matches its ONIX record | [EditionReceipt](https://www.agensi.io/skills/editionreceipt-compare-onix-with-the-delivery-epub) | [Compare a fictional ONIX feed and delivery EPUB](editionreceipt/) |

## Run your first job

1. Read the listing and check that it supports your input. Preview the included report when an example is available.
2. Connect your preferred agent to Agensi and complete the chosen purchase through Agensi.
3. Ask the agent to use the skill on a selected file in your workspace. Check the listing for the agent permissions and tools the skill needs.

For the full collection, including the free file-processing skills, open the [Israel Diego creator storefront](https://www.agensi.io/creators/israel-diego).
